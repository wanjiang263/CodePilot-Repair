# Community conduct

Participants in issues, discussions and pull requests should be respectful, constructive and considerate. Critique ideas and code with evidence. Welcome people with different backgrounds and levels of experience.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing and publication of private information are not acceptable.

Maintainers may edit or remove harmful content, close disruptive discussions, and restrict participation. Apply these measures consistently and proportionately, and explain decisions where doing so will not expose private information.

Report concerns privately to [jeq0731@gmail.com](mailto:jeq0731@gmail.com). Include relevant context and links, with unnecessary personal information removed. Reports are handled by the project maintainer; information should only be shared as needed to investigate and respond. There is no guaranteed response time.
